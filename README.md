# Habits & Health: Factor Association Analysis

A data science project investigating how four lifestyle habit blocks — **balanced diet, sleep, stress level, and physical activity** — are associated with health indicators (BMI, blood pressure, heart rate, sleep disturbances), and which factor shows the strongest association.

**Team:** 1 Data Analyst + 2 ML Engineers  
**Stack:** Python (pandas, numpy, matplotlib, scikit-learn)  
**Data sources:** AI4FoodDB, BRFSS 2024, NHANES

> ⚠️ This project examines **association, not causation**. All findings are correlational.

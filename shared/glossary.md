# Глоссарий команды

| Термин | Значение |
|---|---|
| **Паспорт источника** | `data/PASSPORT.md`: ссылка, лицензия, дата скачивания и sha256 файлов. Без него анализ не начинается. |
| **Блок признаков** | Группа колонок одной темы: питание, сон, стресс, активность. |
| **Целевая переменная** | Бинарный исход, который объясняет модель. Определяется в `spec.md`. |
| **Baseline** | Простейшее предсказание (доля положительного класса). Точка отсчёта для модели. |
| **Логистическая регрессия** | Линейная модель для бинарного исхода; коэффициенты переводятся в odds ratio. |
| **Odds ratio (OR)** | Во сколько раз меняются шансы исхода при росте признака на 1 единицу (или 1 SD). |
| **Стандартизованный коэффициент** | Коэффициент после масштабирования признаков; позволяет сравнивать силу разных факторов. |
| **Permutation importance** | Падение метрики при случайной перестановке одного признака; мера вклада в предсказание. |
| **95% CI** | Интервал, в который с вероятностью 95% попадает оценка при повторении выборки (bootstrap). |
| **Выброс** | Наблюдение, резко отличающееся от остальных; помечается, а не удаляется автоматически. |
| **Complete-case** | Анализ только строк без пропусков в используемых колонках. |
| **Утечка (leakage)** | Информация из test попадает в обучение; завышает метрики. |
| **Ассоциация** | Статистическая связь без утверждения причины. |
| **Причинность** | Утверждение, что X вызывает Y; в наблюдательных данных без дизайна не заявляется. |
| **Confounder** | Третья переменная, искажающая связь X и Y. |
| **Checker** | Агент/скилл, проверяющий артефакты по рубрике и пишущий `review/report.json`. |
| **Рубрика** | `shared/rubric/practice-v1.json`: критерии, веса, запреты. |
| **ok / partial / missing** | Статусы критерия: выполнен / частично / отсутствует. |
